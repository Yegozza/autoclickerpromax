# AutoClicker Pro Max — Автокликер

> Десктопное приложение для автоматизации кликов мыши.
> **Проект создан в учебных целях для практики тестирования.**

---

## 📋 Описание проекта

**AutoClicker Pro Max** — приложение с графическим интерфейсом, которое автоматически выполняет клики мыши. Поддерживает два режима работы, настройку скорости, ограничения по количеству кликов или времени, а также сохранение профилей настроек.

### Основные функции

| Функция | Описание |
|---------|----------|
| 🖱 Режим "Следовать за мышью" | Клики в текущей позиции курсора |
| 📍 Режим "По заданным позициям" | Клики по заранее заданным координатам |
| ⚡ Настройка скорости | 5 предустановленных режимов + ручной ввод интервала |
| 🔢 Ограничения | По количеству кликов или по времени |
| 💾 Профили | Сохранение и загрузка настроек |
| 🎨 Темы оформления | Темная и светлая |
| 📌 Маркеры позиций | Визуальное отображение сохраненных позиций |
| 🔝 Поверх всех окон | Возможность закрепить окно поверх других |

## 🔍 Анализ найденных багов

Все найденные дефекты связаны с модулем **скорости кликов**. Это указывает на системную проблему в реализации таймингов.

### Наблюдение
При увеличении заявленной скорости кликов **фактическая производительность падает пропорционально**:

| Режим | Заявленный интервал | Ожидалось кликов/10с | Фактически | Отклонение |
|-------|--------------------|--------------------:|-----------:|-----------:|
| Медленно | 0.5 сек | 20 | 20 | 0% |
| Средне | 0.1 сек | 100 | 92 | -8% |
| Быстро | 0.05 сек | 200 | 171 | -14.5% |
| Очень быстро | 0.01 сек | 1000 | 604 | -39.6% |
| Мгновенно | 0.001 сек | 10000 | ~2800 | -72% |
